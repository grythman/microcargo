# 📦 MicroCargo

Карго бизнест зориулсан энгийн захиалга бүртгэх веб сайт.

Excel дээр гараар бичиж, Facebook группдээ зураг тавьдаг ажлыг орлоно. Хамгийн гол давуу тал нь: **захиалагч бүр зөвхөн өөрийн утасны дугаарт хамаарах захиалгаа л хардаг** — бусдын мэдээлэл харагдахгүй.

## Хэрхэн ажилладаг вэ?

- **Админ (карго оператор — та)**: тусдаа нэвтрэлтээр орж, захиалга бүрийг утасны дугаараар нь бүртгэнэ (барааны нэр, тоо ширхэг, нэгж үнэ, нийт үнэ, төлөв, трак код, тэмдэглэл).
- **Захиалагч**: өөрийн утасны дугаар + нууц үгээр бүртгүүлж/нэвтэрч, тэр дугаарт бүртгэгдсэн захиалгуудаа л хардаг.

Холбоос нь утасны дугаар: админ ямар дугаараар захиалга бүртгэнэ, захиалагч тэр дугаараар нэвтэрвэл захиалга нь автоматаар харагдана.

## Шаардлага

- [Node.js](https://nodejs.org/) 18 буюу түүнээс дээш хувилбар

## Суулгах ба ажиллуулах

```bash
# 1. Хамаарлуудыг суулгах
npm install

# 2. Тохиргооны файл үүсгэх
cp .env.example .env
#  -> .env дотор JWT_SECRET, ADMIN_USERNAME, ADMIN_PASSWORD-оо солих

# 3. Серверээ асаах
npm start
```

Дараа нь хөтөч дээрээ:

- Захиалагчийн хэсэг: <http://localhost:3000>
- Админ хэсэг: <http://localhost:3000/admin.html>

## Тохиргоо (`.env`)

| Хувьсагч | Тайлбар | Анхдагч |
|----------|---------|---------|
| `PORT` | Серверийн порт | `3000` |
| `JWT_SECRET` | Нэвтрэлтийн токен баталгаажуулах нууц түлхүүр (заавал солих) | — |
| `ADMIN_USERNAME` | Админ нэвтрэх нэр | `admin` |
| `ADMIN_PASSWORD` | Админ нууц үг | `admin123` |
| `DB_PATH` | SQLite өгөгдлийн сангийн файлын зам | `./data/microcargo.db` |

> ⚠️ Production дээр заавал `JWT_SECRET`-ийг урт, санамсаргүй утгаар, `ADMIN_PASSWORD`-ийг хүчтэй нууц үгээр солино уу.

## Ердийн ажлын урсгал

1. Та (админ) `/admin.html` дээр нэвтэрнэ.
2. Захиалагчийн утасны дугаараар шинэ захиалга нэмнэ.
3. Захиалагч таны вэб хаягаар орж, өөрийн дугаараар бүртгүүлж/нэвтэрнэ.
4. Захиалагч зөвхөн өөрийн захиалга, төлөв, төлбөрийн дүнгээ хардаг.

## Техникийн мэдээлэл

- **Backend**: Node.js + Express
- **Өгөгдлийн сан**: SQLite (`better-sqlite3`) — нэг файлд хадгалагдана
- **Нэвтрэлт**: JWT токен, нууц үг `bcrypt`-ээр хэшлэгдэнэ
- **Frontend**: энгийн HTML/CSS/JavaScript (build хэрэггүй)

### Төслийн бүтэц

```
microcargo/
├── server.js          # Express сервер ба API
├── db.js              # SQLite холболт ба хүснэгтүүд
├── package.json
├── .env.example
└── public/            # Frontend
    ├── index.html     # Захиалагчийн хэсэг (нэвтрэх + захиалга харах)
    ├── admin.html     # Админ хэсэг
    ├── css/style.css
    └── js/
        ├── common.js
        ├── customer.js
        └── admin.js
```

### API товч

| Method | Зам | Тайлбар |
|--------|-----|---------|
| `POST` | `/api/auth/register` | Захиалагч бүртгүүлэх |
| `POST` | `/api/auth/login` | Захиалагч нэвтрэх |
| `GET`  | `/api/my/orders` | Нэвтэрсэн захиалагчийн захиалгууд |
| `POST` | `/api/admin/login` | Админ нэвтрэх |
| `GET`  | `/api/admin/orders?phone=` | Бүх (эсвэл дугаараар шүүсэн) захиалга |
| `POST` | `/api/admin/orders` | Захиалга нэмэх |
| `PUT`  | `/api/admin/orders/:id` | Захиалга засах |
| `DELETE` | `/api/admin/orders/:id` | Захиалга устгах |
